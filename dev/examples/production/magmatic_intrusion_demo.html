High-enthalpy geothermal system above a magmatic intrusion ​

Production  

This example demonstrates simulation of a high-enthalpy geothermal system heated by a cooling magmatic intrusion, inspired by the production and reinjection scenarios of []. The fluid is pure water, modelled with the pressure-enthalpy formulation in Fimbul (H2OSystem), so the reservoir may contain liquid, vapor, two-phase and supercritical water.

The example consists of two parts:

  1. Natural state: A 900 °C intrusion is emplaced 2–3 km below the surface and left to develop a hydrothermal convection system for 2400 years.

  2. Production: Starting from the natural state, we compare 100 years of production with and without reinjection of cold water.

Add required modules to namespace

julia
using Jutul, JutulDarcy, Fimbul
using HYPRE
using GLMakie

Useful SI units

julia
meter, year = si_units(:meter, :year);

Set up the natural-state case ​

The domain is 10 km × 10 km × 5 km, with an ellipsoidal intrusion of horizontal radius 1.5 km centered horizontally. We use a relatively coarse tensor mesh to keep the runtime moderate. The mesh has uniform cells horizontally across the intrusion and vertically from the base of the cap rock to the bottom of the intrusion, so that the convection plume above the intrusion is resolved, and cells growing towards the domain boundaries. Fluid can flow along the wellbore of a shut well, so we simulate the natural state without wells by setting num_years = 0. The wells are added when we set up the production scenarios.

julia
dims = (41, 41, 40)
case_args = (
    dims = dims,
    injector_position = (0.0, 0.0).*meter,
    cell_growth = 1.25,
)
case_ns = magmatic_intrusion(; case_args...,
    natural_state_time = 2400.0year,
    num_years = 0,
)
model = reservoir_model(case_ns.model)
mesh = physical_representation(model.data_domain);

Inspect the model ​

We first inspect the model interactively, starting with the initial temperature. Other properties can be selected in the viewer, e.g., the permeability, which shows the low-permeability cap rock covering the top 500 m of the domain. For the 3D plots in this example, we cut away the quadrant of the domain facing the viewer, so that the cut planes pass through the center of the intrusion.

julia
xc = model.data_domain[:cell_centroids]
x_mid = sum(extrema(xc[1, :]))/2
y_mid = sum(extrema(xc[2, :]))/2
cutaway = .!(xc[1, :] .< x_mid .&& xc[2, :] .< y_mid)
axis_args = (zreversed = true, aspect = :data, perspectiveness = 0.75, elevation = π/16)
plot_res_args = (
    resolution = (1000, 800), aspect = :data,
    axis_args = axis_args,
    cells = cutaway,
    fancy = false
)
plot_reservoir(case_ns; key = :Temperature, plot_res_args...)

Simulate the natural state ​

We use the same solver settings for all simulations in this example: we remove the default maximum timestep of one year, since the system evolves slowly once the convection pattern is established, use relaxation of the Newton updates, and use slightly relaxed convergence tolerances. Close to the critical point of water, the fluid properties change rapidly, and these settings help the nonlinear solver through this region. We also limit the change in enthalpy per timestep.

Note that the natural-state simulation takes a while to run. The early, transient part of the simulation, when the intrusion cools and a two-phase region develops above it, requires many short timesteps. Once the convection pattern is established, the timesteps increase.

julia
function run_case(case)
    sim, cfg = setup_reservoir_simulator(case;
        max_timestep = Inf,
        relaxation = true,
        tol_cnv = 1e-2,
        tol_mb = 1e-5,
        info_level = 0
    )
    tss = VariableChangeTimestepSelector(:Enthalpy, 1e5;
    relative = false, model = :Reservoir)
    push!(cfg[:timestep_selectors], tss)
    return simulate_reservoir(case; simulator = sim, config = cfg)
end

results_ns = run_case(case_ns);

The interactive viewer shows the temperature at each report step of the natural state. Filtering out low temperatures shows how the hot plume develops above the intrusion.

Development of the convection plume ​

The hot intrusion heats the surrounding water, which rises buoyantly and is replaced by colder water flowing in from the sides. We plot the temperature (top) and liquid saturation (bottom) at selected times.

julia
t_ns = cumsum(case_ns.dt)
nearest_step(t) = argmin(abs.(t_ns .- t))
plot_times = [300.0, 600.0, 1200.0].*year
T_range = (10.0, 900.0)
fig = Figure(size = (1200, 750))
for (i, t) in enumerate(plot_times)
    step = nearest_step(t)
    T = convert_from_si.(results_ns.states[step][:Temperature], :Celsius)
    ax = Axis3(fig[1, i];
        title = "$(round(Int, t_ns[step]/year)) years", axis_args...)
    plot_cell_data!(ax, mesh, T; cells = cutaway,
        colormap = :seaborn_icefire_gradient, colorrange = T_range)
    hidedecorations!(ax)
    S = results_ns.states[step][:Saturations][1, :]
    ax = Axis3(fig[2, i]; axis_args...)
    plot_cell_data!(ax, mesh, S; cells = cutaway,
        colormap = :gray1, colorrange = (0.0, 1.0))
    hidedecorations!(ax)
end
Colorbar(fig[1, length(plot_times) + 1]; colormap = :seaborn_icefire_gradient,
    colorrange = T_range, label = "T (°C)")
Colorbar(fig[2, length(plot_times) + 1]; colormap = :gray1,
    colorrange = (0.0, 1.0), label = "Liquid saturation")

Phase diagram ​

The evolution of the fluid can be shown in a pressure-enthalpy phase diagram, with temperature contours and the two-phase envelope. We follow four cells on the vertical line through the center of the intrusion: one at the center of the intrusion, one just above it, one higher up in the convection plume, and one near the surface. Each line shows the state of one cell at every report step of the natural state (circles), starting from the initial state (star). Early in the natural state, the fluid passes close to the critical point of water (22.064 MPa, 2.085 MJ/kg), where the fluid properties change rapidly. This is the most challenging part of the simulation.

julia
x_c = (x_mid, y_mid)
probe_depths = [2500.0, 1900.0, 1300.0, 700.0].*meter
probe_cells = [argmin((xc[1, :] .- x_c[1]).^2 .+ (xc[2, :] .- x_c[2]).^2 .+
    (xc[3, :] .- d).^2) for d in probe_depths]
probe_labels = ["Intrusion center", "Above intrusion", "Upper plume", "Near surface"]
probe_colors = [:red, :lightgreen, :cyan, :magenta]
states_ph = vcat([case_ns.state0[:Reservoir]], results_ns.states)
tables = model.system.pvt_tables
fig = Figure(size = (900, 650), fontsize = 14)
ax = Axis(fig[1, 1])
handles = plot_phase_diagram_contours!(ax, tables;
    pressure_limits = (0.0, 30e6), enthalpy_limits = (0.0, 4.5e6), lines = true)
for (i, (c, label)) in enumerate(zip(probe_cells, probe_labels))
    h = [state[:Enthalpy][c] for state in states_ph]./1e3
    p = [state[:Pressure][c] for state in states_ph]./1e6
    depth = round(Int, xc[3, c])
    lines!(ax, h, p; color = probe_colors[i], linewidth = 3, label = "$label ($depth m)")
    scatter!(ax, h, p; color = probe_colors[i], markersize = 10,
        strokecolor = :black, strokewidth = 1)
    scatter!(ax, h[1:1], p[1:1]; color = :yellow, markersize = 12,
        strokecolor = :black, strokewidth = 1, marker = :star5)
end

Production scenarios ​

We set up the production scenarios with wells, starting from the end of the natural state (initial_state), and simulate 100 years of production. The wells are multisegment wells that extend from the surface, and the well pressures are prescribed at the wellhead. The producer is open between 750 and 1750 m depth, above the intrusion, and is operated at a wellhead pressure of 10 bar. In the second scenario, cold water (80 °C) is reinjected at a wellhead pressure of 80 bar in an injector that is open between 1750 and 1950 m depth, just above the intrusion. With injection_years = 0, the injector is not included in the model. We use report steps of one year.

julia
state_ns = results_ns.states[end]
case_inj = magmatic_intrusion(; case_args...,
    natural_state_time = 0.0,
    num_years = 100,
    report_interval = 1.0year,
    initial_state = state_ns,
)
case_noinj = magmatic_intrusion(; case_args...,
    natural_state_time = 0.0,
    num_years = 100,
    injection_years = 0,
    report_interval = 1.0year,
    initial_state = state_ns,
)
wells = get_model_wells(case_inj.model)
function plot_wells!(ax)
    for well in values(wells)
        plot_well!(ax, mesh, well;
            color = :black, linewidth = 3, markersize = 0.0, fontsize = 0.0)
    end
end

Well performance ​

The produced fluid boils as it rises in the producer, and reaches the wellhead as a mixture of water and steam. The production temperature is therefore fixed at the saturation temperature at the wellhead pressure of 10 bar (about 180 °C) throughout the simulation. The specific enthalpy of the produced fluid, which determines the steam fraction, varies only slightly. We therefore show the power output, computed as the produced mass rate times the specific enthalpy of the produced fluid, which closely follows the production rate. The power output drops quickly in the first years as the pressure around the producer declines. Reinjection supports the reservoir pressure, which sustains a higher production rate and power output.

julia
fig = Figure(size = (800, 450))
ax = Axis(fig[1, 1]; xlabel = "Time (years)", ylabel = "Power output (MW)")
colors = Makie.wong_colors()
for (i, (res, label)) in enumerate(zip(
        [results_noinj, results_inj], ["Production only", "With reinjection"]))
    t = res.time./year
    q = -res.wells[:Producer][:mass_rate]
    h = [state[:Producer][:Enthalpy][1] for state in res.result.states]
    lines!(ax, t, q.*h./1e6; color = colors[i], linewidth = 2, label = label)
end
axislegend(ax; position = :rt)

Reservoir temperature change ​

Finally, we plot the temperature change relative to the natural state for the scenario without (left) and with (right) reinjection. The region along the producer cools, while hot fluid drawn up from the plume warms the rock next to it. Reinjection creates a cold zone around the injector.

julia
T_ns = results_ns.states[end][:Temperature]
results_prod = (results_noinj, results_inj)
ΔT_all = [res.states[end][:Temperature] .- T_ns for res in results_prod]
ΔT_max = maximum(maximum.(ΔT_all))
ΔT_min = minimum(minimum.(ΔT_all))
ΔT_range = (ΔT_min, ΔT_max)
